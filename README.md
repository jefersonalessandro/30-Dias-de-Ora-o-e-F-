# Landing page - 30 Dias de Oração e Fé

Página estática pronta para publicar na Vercel.

## Arquivos

- `index.html`: página principal.
- `assets/hero-devocional.png`: imagem usada no topo da página.

## Publicar na Vercel

1. Crie um repositório no GitHub com estes arquivos.
2. Na Vercel, clique em `Add New Project`.
3. Importe o repositório.
4. Mantenha as configurações padrão para projeto estático.
5. Clique em `Deploy`.

Depois do deploy, use a URL da Vercel como URL final no Google Ads.

O botão de compra da página envia para:
